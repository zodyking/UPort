# Code of conduct

This project is discussed in GitHub issues and pull requests. Keep that space usable.

- Critique the app and the change, not the person.
- No harassment, slurs, or sexual content.
- Do not post other people’s camera feeds, door events, addresses, or credentials.
- Assume a good-faith reading of a short bug report.

Maintainers may edit or hide comments that break these points, and may block repeat abuse. Questions about a moderation decision can go to [zodykinginbox@gmail.com](mailto:zodykinginbox@gmail.com).
